## Aperçu

L'AESM accompagne les étudiants sénégalais dans leur intégration à Montpellier. Le site centralise les événements, les démarches administratives et les services d'entraide, avec un espace membre et un back-office pour le bureau de l'association.

## Fonctionnalités clés

- **Événements** : agenda et mise en avant des temps forts
- **Guide étudiant** : démarches, logement, attestations d'hébergement
- **Espace membre** : inscription, connexion, profil
- **Demandes d'entraide** : solidarité, mentorat, jobs et stages
- **Cagnottes solidaires** avec **paiement en ligne sécurisé (Stripe)**
- **Back-office** pour gérer les contenus, les événements et les demandes
- E-mails automatiques

## Architecture technique

| Couche | Technologies |
|---|---|
| Front-end | Next.js (App Router), TypeScript |
| Back-end et base de données | Supabase (PostgreSQL, authentification) |
| Paiements | Stripe Checkout, avec webhook de confirmation |
